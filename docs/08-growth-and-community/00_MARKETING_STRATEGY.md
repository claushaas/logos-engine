# Marketing Strategy

## Positioning

LOGOS Engine is an open-source local-first TUI for turning ideas into complete documentation before building.

## Category

Potential category:

```text
Structured Intent Documentation Tool
```

Alternative:

```text
Local-First Venture and Project Design System
```

## Core Message

Before you build, clarify.

## Audience

Initial audience:

- technical founders;
- indie hackers;
- developers building products;
- product-minded engineers;
- open-source builders;
- agencies;
- consultants.

## Differentiation

LOGOS Engine differs from generic AI tools because it:

- runs locally;
- writes to your repository;
- creates canonical docs;
- tracks decisions;
- exposes gaps;
- works with Git;
- is open source;
- is profile-driven.

## Launch Channels

### Primary

- GitHub;
- Hacker News;
- Reddit communities;
- X/Twitter;
- LinkedIn;
- developer Discords;
- indie hacker communities.

### Secondary

- blog posts;
- demo videos;
- YouTube walkthrough;
- newsletters;
- open-source directories.

## Content Themes

- why projects fail before code;
- documentation as structured thinking;
- decision registry vs static docs;
- building before clarity;
- open-source venture building;
- local-first AI-assisted tooling;
- TUI as product interface.

## Messaging Constraints

Avoid:

- "AI will build your startup";
- "guaranteed success";
- "replace founders";
- hype-heavy positioning.

Prefer:

- clarity;
- structure;
- auditability;
- practical usefulness.
