# Content Strategy

## Purpose

Content should educate builders on structured clarity before execution.

## Core Content Pillars

### 1. Before You Build

Topics:

- why app projects drift;
- why docs fail;
- how to avoid preventable pivots;
- how to clarify before coding.

### 2. Decision-First Documentation

Topics:

- decisions as source of truth;
- docs as projections;
- assumptions vs facts;
- living documentation.

### 3. Local-First Tooling

Topics:

- why terminal-first works;
- Git as memory;
- Markdown as interface;
- IDE as workspace.

### 4. App Business Design

Topics:

- product thesis;
- MVP scope;
- unit economics;
- pricing;
- GTM;
- retention.

### 5. Open Source Venture Tooling

Topics:

- giving back;
- free learning infrastructure;
- community profiles;
- transparent methodology.
