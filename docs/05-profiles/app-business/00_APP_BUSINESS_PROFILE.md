# App Business Profile

## Purpose

The App Business profile helps a user transform an app idea into a complete documentation package covering business, product, design, engineering, launch, and operations.

## Target User

A technical or semi-technical builder who wants to build an app-based business.

## Profile Outcome

At the end of the process, the user should have enough documentation to:

- evaluate the opportunity;
- understand the business model;
- define the MVP;
- design the user experience;
- architect the system;
- implement the product;
- test it;
- launch it;
- operate it;
- evolve it.
