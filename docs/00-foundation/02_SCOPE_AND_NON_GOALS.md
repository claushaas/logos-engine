# Scope and Non-Goals

## V1 Scope

The first version of LOGOS Engine should support:

- initializing a project workspace;
- selecting the App Business profile;
- creating a canonical folder structure;
- asking guided questions;
- storing structured decisions;
- rendering Markdown documents;
- identifying open gaps;
- running basic validation;
- showing progress by phase;
- allowing the user to continue later;
- working inside an existing project repository.

## V1 Non-Goals

The first version should not attempt to support:

- cloud sync;
- multi-user collaboration;
- web dashboard;
- payment;
- plugin marketplace;
- full AI autonomy;
- multi-agent orchestration;
- complex financial simulations;
- full dependency graph visualization;
- real-time external market research;
- automatic code generation.

## Why These Non-Goals Matter

LOGOS Engine can easily become too large.

The first version must prove that structured clarification and documentation generation is valuable.

Only after that should the system expand into deeper intelligence, external integrations, and additional profiles.

## Expansion Candidates

After V1:

- additional profiles;
- richer validation engine;
- dependency graph;
- AI-assisted document refinement;
- financial modeling;
- market research integrations;
- agent prompt generation;
- roadmap-to-task export;
- GitHub issue generation;
- Figma export;
- OpenCode/OpenClaw integration.
