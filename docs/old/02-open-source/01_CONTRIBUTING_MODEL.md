# Contributing Model

## Contribution Types

LOGOS Engine should support contributions in several layers.

## 1. Core Engine Contributions

Examples:

- TUI improvements;
- renderer improvements;
- validation engine;
- storage system;
- configuration loader;
- diagnostics;
- tests.

## 2. Profile Contributions

Examples:

- app-business improvements;
- SaaS profile;
- course profile;
- ecommerce profile;
- agency profile;
- research profile.

## 3. Document Template Contributions

Examples:

- better PRD templates;
- improved architecture documents;
- market analysis templates;
- launch plans;
- risk registers.

## 4. Question Pack Contributions

Examples:

- better founder intake questions;
- pricing questions;
- UX questions;
- architecture questions;
- marketing questions.

## 5. Validation Rule Contributions

Examples:

- if pricing is undefined, economics are incomplete;
- if offline-first is selected, sync strategy is required;
- if B2C paid acquisition is selected, CAC model is required.

## 6. Examples

Example projects are crucial.

The repository should include anonymized sample workspaces demonstrating:

- minimal app-business project;
- complex app-business project;
- website project later;
- course project later.

## Contribution Requirements

Each contribution should include:

- purpose;
- affected profile or module;
- tests where relevant;
- documentation update;
- migration note if needed.

## Review Principles

Review should prioritize:

- clarity;
- maintainability;
- user value;
- schema stability;
- avoiding unnecessary abstraction.
