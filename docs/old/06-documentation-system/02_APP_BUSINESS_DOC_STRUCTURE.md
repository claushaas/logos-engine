# App Business Documentation Structure

## Purpose

This document defines the canonical document tree for the App Business profile.

## Tree

```text
docs/
  00-intake/
  01-market/
  02-business/
  03-economics/
  04-product/
  05-design/
  06-architecture/
  07-implementation/
  08-testing/
  09-go-to-market/
  10-operations/
  11-governance/
```

## Folder Responsibilities

### 00-intake

Initial idea and uncertainty.

### 01-market

Market, audience, competitors, and alternatives.

### 02-business

Business model, positioning, and value capture.

### 03-economics

Costs, pricing, margin, projections, and break-even.

### 04-product

Product thesis, MVP, features, roadmap.

### 05-design

UX, interface direction, onboarding, flows.

### 06-architecture

Technical architecture, data, APIs, stack.

### 07-implementation

Execution plan, standards, milestones.

### 08-testing

Test strategy and quality gates.

### 09-go-to-market

Marketing, launch, content, acquisition.

### 10-operations

Support, monitoring, metrics, maintenance.

### 11-governance

Decision log, risk register, assumptions.
